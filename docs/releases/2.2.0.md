# 芙兰水衣 FlandreSY 2.2.0

发布日期：2026-10-17。

## 外观与交互

- 设备列表改用“运行中”等简短状态，不再用长提示挤占设备名称和编号；完整说明可点击查看。
- 热水控制卡片的状态标题和提示保持单行，长异常可点开阅读，减少状态切换时的页面跳动。
- 首页进行中的洗衣、热水和饮水卡片更紧凑，任务出现时不再撑开原有区域。
- 调整 798 设备卡片的名称、编号和状态排布，改善窄屏与大字号下的显示。

## 设备与订单

- 修复设备列表刷新与编辑同时进行时互相覆盖的问题。
- 完善设备导入检查，错误内容会给出提示；保存失败时保留原列表，避免误报成功。
- 设备刷新显示真实查询结果，旧结果与查询失败有明确区分。
- 改善洗衣订单状态同步，使跨页面和返回应用后的显示与可用操作保持一致。
- 热水历史按账号展示，旧档案继续保留；加载失败与暂无记录分别提示，并可重试。
- 修复 798 设备未查询却显示待机的问题，改善登录、设备选择及保存结果的反馈。

## 旧数据保留

- 移除模拟模式，应用统一连接真实服务。
- 保留旧设备、设置与业务记录，各服务首次使用需要重新登录。
- 来源不明的活动继续保留待核对，不自动删除，也不据此控制设备；可在“更多选项 → 旧数据保全”查看进度和重试。
- 已有账号归属保持隔离，无归属旧档案保留待核对，避免误归给当前账号。

## 提示与可靠性

- 改善网络超时和异常响应提示，未确认的操作结果不再误报为成功。
- 权限在需要时申请，设置跳转和权限检查结果更明确。
- iOS 住理蓝牙热水控制明确提示暂不可用，并保留旧会话信息。
- 改善更新检查与下载入口反馈，iOS 不再出现 Android 安装包入口。
- 修复诊断日志清空后旧内容重新出现的问题；清空失败可重试，诊断内容减少敏感信息。
