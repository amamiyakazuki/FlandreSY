# FlandreSY 2.1.3

本版聚焦业务稳定性，版本号为 `2.1.3+5`。

## 更新内容

- 修复热水连续点击重复启动：合并重复请求，已有会话不重复发送启动协议，保留原时间与关水凭据。
- 保持开关按钮可点击；重启／回前台时，距开水超过 40 分钟恢复待开水并更新可用订单，未超过则保持已开水。这是本地恢复规则，不会自动发送关水指令。
- 修复账号切换、登录失效和旧请求响应的竞态；保护饮水、洗衣活动订单，不用新订单覆盖尚未确认结束的订单。
- 加强持久化和损坏数据保留、网络请求超时、BLE 目标匹配及连接清理。
- 支持 Debug 与正式版共存，新增自动分析、测试与 Android Debug 构建 CI。

## 下载与升级

- 推荐 `app-release.apk`：包含 ARM64 与 x86_64，使用正式签名，包名仍为 `com.flandresy`。
- `app-arm64-v8a-release.apk`：ARM64 专用安装包。
- `app-x86_64-release.apk`：x86_64 专用安装包。
- `app-release.aab`：应用商店发布格式，不可直接点击安装。
- 不支持 32 位 ARM。本次不提供 iOS 签名安装包。
- 优先覆盖安装以保留本地记录；若安装提示签名不兼容，请先核对来源，不要卸载仍有活动订单的旧版本。
- 升级请沿用上版下载的文件类型：主 APK 版本码为 5，ARM64／x86_64 专用包分别为 2005／4005。专用包改装主 APK 会被 Android 视为降级；不要通过卸载来绕过。

## 验证边界

热水相关现场验证由用户反馈通过；本轮未新增真实支付验证。现有 129 项自动测试及 Android CI 已通过，UI 重设计不包含在本次更新中。
