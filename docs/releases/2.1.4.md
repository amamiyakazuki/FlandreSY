# FlandreSY 2.1.4

版本：`2.1.4+6`。

## 更新内容

- 无归属旧洗衣、饮水订单默认关联最近登录的U净账号，已有归属不变；保留订单并恢复更新。
- 首页进行中卡片等宽三等分、紧凑间距，不足三项靠左，不增加默认高度。
- 住理、U净、798新增本地登出、进入账号页一次检测与手动检测；区分登录失效与网络暂不可验证，不后台轮询。
- 登出保留订单、设备配置和热水会话，不代表停止实体设备；设备操作在途时提示稍后退出。
- 热水待确认不再显示绿色运行态，区分历史加载、读取失败与真正无记录。
- 详情长文字自然换行，窄屏或大字号下按钮纵排，保持可点击，不改变业务规则。

- `app-release.apk`：ARM64与x86_64通用包，正式包名`com.flandresy`。
- `app-arm64-v8a-release.apk`、`app-x86_64-release.apk`：对应架构专用包。
