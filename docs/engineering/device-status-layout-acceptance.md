# 设备状态文案与布局小修

## 范围与约定

用户截图中旧版设备卡片的“此设备正在运行中，请使用其他设备”挤占名称和编号。当前 main 已移除列表右侧标签，但完整状态/查询时间仍会无限换行。用户授权修复本问题并检查同类设备卡片，其他建议模块暂缓。

本轮只修改本地设备列表与 798 设备卡片的展示及测试；不改变原始状态数据、刷新请求、可信标记、设备操作与下单条件。洗衣详情的标签本身是固定“待扫码 / 可下单 / 不可下单”，未发现截图中的原始长句用法，未改该页。未开展全站视觉重设计。

- 已确认的截图运行提示精确映射为“运行中”，避免把“未运行”“运行失败”等误判成运行。
- 本地设备查询失败显示“查询失败”；缓存结果显示“待核对”；未查询显示“未查询”。其他六字以内状态保留，其他长状态显示“查看状态”。
- 状态固定单行，原文、查询时间或未核对说明放入可滚动详情；点状态不会触发卡片原操作。
- 798 名称、编号、状态改成上下排布，状态不再抢占名称宽度；当前设备仍有原高亮及“当前设备”标识。其未确认缓存仍只显示“状态未查询”，不把旧空闲状态当作当前状态。
- 普通字号下测试设备名称/编号完整显示；超长名称或大字号下允许既有省略，完整名称和编号可在状态详情查看。
