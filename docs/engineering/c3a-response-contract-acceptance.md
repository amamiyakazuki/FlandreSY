## 实际变化与限制

- 798 的成功文案为“启动/停止请求已确认，请核对设备”，不再把接口确认直接表述为物理水流事实；未新增设备查询或自动重发。
- 798 master 缺 account 曾被当作失效；现改为响应不完整，保留登录。对应旧测试预期已按批准方案更新，未削弱明确 401/403 回归。
- code 为字符串 "0" 会拒绝，这是用户选择的 A 规则；真实服务兼容性仍需脱敏响应或真机确认。
- 未进行真实登录、付款、BLE、设备开关或 C1 覆盖升级验收。CI 只能证明分析、自动测试与构建情况。
- C2 列表竞争、C3b 状态同步、D1 登录反馈分类等问题未处理；不能把本次响应校验当成这些模块已完成。
